## What the ADR does and does not forbid — read this carefully

`.context/decisions/2026-07-25-map-geometry-is-a-pure-slot-layout.md` was initially read as refusing aesthetic change. It does not. It refuses **four named alternatives**, plus baked text:

- a graph library or force simulation — nondeterministic, and nodes that drift while you aim at one are worse than plain nodes;
- a plain per-depth band — a nested child can land far from its parent and edges cross, and nesting is the one thing the map exists to show;
- wrapping a crowded band into a grid — makes "depth separates nodes" stop being obvious;
- per-node captions — cannot fit, and conditional labels make the picture jump between agent counts.

And its **Reversibility** section says the opposite of a freeze:

> **Easy.** The geometry is one pure exported function with no callers besides `AgentMap.tsx`; a different layout is a rewrite of that function and its tests, with no change to the tree, the dock, or the merge.

So: the layout may be rewritten. The encoding and the four rejected shapes may not.

## Hard constraints

- **Keep `shape = kind, colour = status`** — rounded square = session, circle = agent, diamond = failed. The criterion is that a failed agent stays findable **in greyscale and at a 4px node**; colour only reinforces. Red-only would fail exactly the users that criterion is written for.
- **No baked text.** Identity lives in each node's `aria-label` and `<title>`; the list stays the labelled view, the map is the shape view.
- **No graph library, no force solver, no new dependency.** Geometry stays a pure function in `src/shared/agent-layout.ts` (252 lines) with `AgentMap.tsx` its only caller.
- **`role="group"` on the map SVG, never `role="img"`** — `role="img"` makes the whole subtree presentational and hides every node button from assistive tech, and **testing-library still finds the buttons under it**, so the suite cannot catch this.
- **The running halo's alpha belongs in the `fill` via `color-mix`, not in `opacity`** — the reused `subagent-pulse` keyframe animates opacity 1 → 0.35 and would override it, flashing the halo near-solid mint.
- **Click-target sizing must be measured within a depth band.** A nested spine stacks parent and child on the same x; measuring the gap across all nodes reads zero and collapses every hit circle to `r=0`, killing the mouse on the entire map. jsdom does no hit testing, so only an assertion on the radius itself catches it.
- The `ponytail:` shortcut in the layout module names its own ceiling (radius floors at 3 units). If you change the layout, keep a comment naming the new ceiling.

## Suggested direction, not binding

Depth spacing, node scale, edge weight and curvature, the halo, hover and selected states, and how the map breathes inside its 180px panel are all fair game. A real 7-agent session currently renders inside 155px of SVG at the 180px clamp floor with no scrollbar on either axis — keep that true.
