- [[2026-07-28-a-scrollbar-belongs-to-the-surface-not-the-component]] — #51 replaces four component-scoped `::-webkit-scrollbar` blocks with **one global rule** and pins that no scoped selector may exist; the reported model-menu bar was four scrollables (`.model-menu`, `.command-list`, `.command-popover`, the composer textarea), and the cause was `DESIGN.md` writing a surface-wide property as *"Chat scrollbar: …"* — per-component wording licensed copy-paste, and the copies had already drifted (`.chat` 10px/3px vs the rails' 8px/2px); a shared class was rejected because it still has to be **remembered** at each new container, which is the same failure with an extra step, whereas a bare pseudo-element covers containers that do not exist yet; 10px/3px kept since both render an identical 4px thumb (transparent border + `background-clip: padding-box`) and it is the larger drag target; `::-webkit-scrollbar-button { display: none }` and a transparent `-corner` are load-bearing, and `scrollbar-width`/`scrollbar-color` must never be mixed in because they suppress the `::-webkit-` vocabulary outright
- [[2026-07-28-sanitizing-replay-markup-is-an-anchor-not-a-strip]] — #50 replaces `unwrapCommandInvocation` with `sanitizeUserText`, one classifier dispatching on the **leading tag of the trimmed message** and returning display text or `null` to drop; the anchor is the safety argument, not a shortcut, because every markup kind occupies a **whole message** in real data (nothing follows a `<command-name>` block in **442 of 442**, a caveat is alone in **419 of 419**) while pasted terminal logs and quoted diagnoses that merely *mention* the markup are genuine user content a mid-string strip would eat — `startsWith` → `includes` is killed by exactly one test, the pasted-log pin; scope is **eight tags, not the three reported**, since `<command-name>`-first (442) is *more* common than the one shape the parser handled (312) and `<task-notification>`/`<system-reminder>`/`<bash-*>` are the same defect in the same table (1258 of 3359 messages, **37%**, arrived raw); ANSI is stripped from **output streams only** because a real recorded argument is `fable[1m]` whose brackets are literal, and `CSI` is built with `String.fromCharCode(27)` because neither a raw ESC byte nor a `\u` escape survives tooling intact; dropping is safe only because `TranscriptMessage` has no meta role, so adding one stays out of scope
- [[2026-07-28-lazy-enrichment-is-a-mount-not-a-scan]] — #49 enriches a bare slash-command row from its own transcript on a **channel of its own** (`session:title-hint`), because sharing `session:transcript` would leave the mandated call count with two possible causes and would ship a whole parsed transcript to derive one line; the trigger is a row **mounting** (hence `SessionRow` as a component), so an off-page row and a collapsed rail cost nothing without any explicit check, and results cache as **promises** keyed by session id so a remount mid-flight cannot start a second read — a resolved `null` ("no substantive prompt" / "load failed") being a cached ANSWER, never a retry; "substantive" is **measured, not read literally**, because the literal definition relabels **59 of 65** rows with raw XML (a slash invocation persists in two shapes and the parser's unwrapper knows only one) and the CLI's skill-body injection accounted for **12 of 15** derivable labels behind one identical 40-char prefix, leaving rows as indistinguishable as before; filtering matches cached labels additively and derives **nothing**, or a keystroke becomes the whole-store scan #43 deleted
- [[2026-07-28-choosing-a-folder-is-not-changing-workspace]] — #48 adds `session:choose-folder`, a chooser that **mutates nothing** (`cancelled` | `selected`), rather than reusing `session:pick-folder`, which chooses *and* runs the engine transition while touching no renderer state — the stale-pane bug #46 exists to prevent, reintroduced by the one ticket that finally exposes the picker, and sharp precisely *because it works*; splitting the two is what makes a cancel free (the handler has no mutation to reach, so an untrusted or window-less call is inert by construction), and since both paths end with a new cwd and a re-rendered sidebar, the pin is on the **call** (`pickFolder` never invoked), never on the DOM; `App.switchWorkspace` and `useChat.adoptSession` are **widened** to a nullable id rather than duplicated, mirroring `SwitchRequest.resumeId` so one reset serves both entry points — and `newChat()` is again the wrong tool (it sends `targetSession(null)`, closing the engine the transaction just warmed, and is gated on the renderer's own `busy`), while the affordance itself stays un-busy-gated so main's refusal remains reachable
- [[2026-07-28-a-workspace-reset-is-a-remount-not-a-state-sweep]] — #47 wires the renderer to #46's transaction over `session:switch-workspace`, and the **composer is keyed on `cwd`**: three pieces of state (draft, attachment tray, autocomplete) live only inside `InputBar`, so a remount is the only exhaustive reset and anything a future ticket adds to the composer becomes workspace-scoped for free — App still clears `cwd` / `useChat` / `openDock` / `pendingInsert` / `openSubagent` explicitly, with `pendingInsert` cleared in the **same commit** as the cwd change because `InputBar` applies an insert *on mount* and a survivor refills the new project's composer with the old project's command; `useChat` gains `adoptSession` (replay **without** `targetSession`, since the transaction already rebuilt and warmed the engine and `chat:target` would tear it straight back down); a foreign row is deliberately **not** `busy`-gated — `Engine.isBusy()` is the one source and disabling the row would make the `busy` refusal unreachable — and the three refusals are one inline `role="status"` line above the composer, distinctly phrased, never a chat message, with backend / permission / model untouched as global preferences
- [[2026-07-28-the-workspace-switch-is-one-transaction-over-ports]] — #46 lands `switchWorkspace({cwd, resumeId})` as one atomic transaction over injected ports in `src/main/switch-workspace.ts` (the electron entry cannot be imported under vitest, and the two things needing proof — the **order** of the success path and the **emptiness** of every rejection — are invisible to a result-only test); precedence `busy → missing-cwd → not-found` is fixed and every predicate runs before the first mutation, so a rejection is a genuine no-op; `resumeId: null` is first-class ("open with a new chat" — clears the target, skips the index, returns `ok`), the `ok` sequence writes the resume target **after** the rebuild so it reaches the new engine rather than the one being closed, and busy is `Engine.isBusy()` (`turnResolve !== null`) rather than a second flag that can disagree with the engine actually running; merged **dormant** — collapsing #46 and #47 into one ticket is the named sharpest failure mode
- [[2026-07-28-the-session-list-is-global-scoping-is-a-render-concern]] — #45 drops the `dir` option so `listSessions` returns the whole store, and moves scoping into the renderer: group by project, filter client-side, cap globally; the **absence** of `dir` is the requirement and gets its own pin (a scoped call returns an identically-shaped list silently missing 36 of 37 projects), which also dissolves #43's open `includeWorktrees` call since the SDK applies it only when `dir` is given; order is a contract — filter the complete metadata, then sort/group, then cap the newest 100 **globally**, because capping first makes a truncated list read as empty and capping per group is 3700 rows at 37 projects; a row outside the open workspace renders but is inert (the pin clicks it and asserts `loadTranscript` never fired), and `cwdKey`'s fold moves to `src/shared/` so both processes group by one rule
- [[2026-07-28-storage-location-is-an-index-not-an-encoding]] — #44 deletes `encodeCwd` and resolves a session's directory by **enumerating** `~/.claude/projects` (names only, 12ms for 61 dirs / 589 entries), because encoding fails *silently* — a synthesized path that does not exist reads back as an empty transcript, and it would have missed **45 of 494** live sessions to drive-letter case drift; the named wrong fix is a case-insensitive compare, which patches those and leaves every other lossy collision live; `cwd` is demoted to a display value plus a duplicate tie-break hint, a miss is a typed `not-found` value rather than a throw and rebuilds **once**, and the 6 cwd-less sessions get their own `missing-cwd` rejection — never an empty result, never a cwd decoded back out of the directory name
- [[2026-07-28-session-metadata-is-the-sdks-job]] — #43 hands the sidebar list to the SDK's `listSessions({ dir, includeProgrammatic: false })` (64 sessions in 199ms live) and deletes the per-file parser outright: `title` is `summary` **verbatim** — no `customTitle ?? summary` coalesce, since 0 of 325 custom titles diverge and only a synthetic divergent fixture can catch a re-added one — and **`messageCount` is removed from the product**, not recomputed or faked with `fileSize`, because the only way to keep the number is to keep the whole cost; the raw-markup sidebar-title defect vanishes for free (0 of 490 summaries carry command markup), replay still parses transcripts, and `includeWorktrees` silently defaults to `true` — an open call for #45
- [[2026-07-28-composer-height-is-css-not-state]] — #42's composer grows via `field-sizing: content` + an 8-line `max-height`, with **no** `scrollHeight` effect and no height in React state: criterion 6's three reset sites (send, external insert, value emptied) stop being behaviour to remember and become structural, since there is nothing to leave stuck; the cost is that jsdom sees none of it, so the stylesheet declarations are pinned against source and the real evidence is the now-committed `gui-42.mjs` driver (Electron 43: 33px empty → 75px at three lines → 180px cap at eight with `scrollHeight` 432 → 33px on clear and on send); **do not add a resize effect to `InputBar`**
- [[2026-07-27-slash-commands-are-a-dumb-pipe]] — PRD C (#36) gives the wrapper no notion of "slash command": typed text goes out unparsed and the CLI resolves it, so a real transcript's `"Unknown command: /mdoel. Did you mean /model?"` is the error path for free; command output gets a `command` role with **no avatar** (the CLI wrote it, not Claude) while informational banners reuse `notice`; the list is re-fetched per open and never cached because `supportedCommands()` already tracks the CLI's pushes; the query warms up at folder-pick and **must be inert on failure** or `terminalError` hands the user a dead composer; and the persisted subtype (`local_command`, ×29 across 80 transcripts) is **not** the streamed one, which is still unobserved — #37 opens with a capture because jsdom greens a branch keyed on a subtype that never arrives
- [[2026-07-25-replay-shows-markers-not-bytes]] — #35 emits an `AttachmentMarker` per non-text block and renders chips, never the payload (measured: 2.17 MB of base64 in one real session replays as a 114 KB DOM); the 1375 array-of-only-text user messages are CLI noise and keep parsing to nothing — a deliberate, mutation-verified pin, not the same bug; `tool_result` short-circuits the branch because across 17295 occurrences it never once co-occurs with text or image; and live bytes vs replay markers stay two renderer fields rather than one union
